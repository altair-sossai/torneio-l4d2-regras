## Formação das Equipes

- A administração selecionará **4 capitães**, considerados os 4 melhores jogadores entre os 16 participantes.
- Será realizado um sorteio para definir a ordem de escolha dos capitães.
- As escolhas seguirão o formato **serpentina (vai e volta)**: na primeira rodada, a ordem será **A, B, C, D**; na rodada seguinte, será **D, C, B, A**.
- A ordem continuará alternando dessa forma até o encerramento das escolhas.
- As escolhas continuarão até que cada capitão tenha selecionado 3 jogadores e as 4 equipes estejam completas, com 4 jogadores cada.
- Depois de formadas, as equipes terão seus elencos definidos para todo o torneio.

## Formato da Competição

- As 4 equipes começarão diretamente nas **semifinais**.
- Um sorteio definirá os confrontos da chave.
- A **Equipe A** enfrentará a **Equipe B**, enquanto a **Equipe C** enfrentará a **Equipe D**.
- Todas as séries serão disputadas em formato **MD3**.
- As equipes vencedoras das semifinais avançarão para a final.
- A final seguirá o mesmo formato MD3 e definirá a equipe campeã.
- A equipe que perder uma MD3 será eliminada do torneio.

![Formato da Competição 2026](assets/competition-format-2026.png)

## Escolha das Campanhas

- Em cada MD3, uma equipe escolherá a primeira campanha e a outra escolherá a segunda.
- Se a série ficar empatada em 1 a 1, a terceira campanha será definida por sorteio.
- Se uma equipe vencer as duas primeiras partidas, a terceira não será disputada.
- Cada campanha poderá ser escolhida apenas uma vez por equipe durante o torneio. A campanha definida por sorteio não contará como escolha da equipe.

## Campanhas

- Não serão usadas campanhas customizadas, apenas as **campanhas originais** do jogo.
- Todas as campanhas originais poderão ser escolhidas, considerando as configurações próprias do **ZoneMod v2.9.1b**.

## Versão do Modo de Jogo

- A versão definida inicialmente para o torneio é a **ZoneMod v2.9.1b**.
- Caso sejam disponibilizadas atualizações, patches de segurança, correções ou outras melhorias relevantes, a organização poderá aplicá-los. Nesse caso, a versão do **ZoneMod v2.9.1b** utilizada no torneio poderá ser atualizada para uma versão superior.

## Substituições e Presença

- **Não haverá jogadores substitutos.**
- Depois da formação das equipes, a desistência ou ausência de um jogador não dará direito a reposição.
- A equipe afetada deverá jogar somente com os integrantes presentes. Caso não dispute o confronto, será desclassificada.

## Durante os Jogos

- Será tolerado um atraso de até **15 minutos** para o início da partida. Após esse período, a administração poderá iniciar o jogo usando o comando `!forcestart`.
- Cada equipe poderá solicitar até 3 pausas usando o comando `!pause`.
- As pausas não deverão exceder **5 minutos**. Após esse período, a administração poderá utilizar o comando `!forceunpause`.
- No início de cada round, as equipes deverão utilizar o comando `!ready` dentro de **5 minutos**. Após esse período, a administração poderá iniciar o jogo usando o comando `!forcestart`.
